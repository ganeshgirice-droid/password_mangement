# Contributing to VaultDB

Thanks for your interest in improving this educational project.

## Before you start

- Open an issue to discuss significant changes before implementing them.
- Keep changes focused and explain the problem they solve.
- Do not use real passwords, personal data, or production credentials in tests, screenshots, sample data, or issue reports.
- Never commit `.env` files, local database files, tokens, or other secrets.

## Development

1. Install Node.js 20 or newer.
2. Install dependencies with `npm install`.
3. Start the local app with `npm run dev`.
4. Run the tests with `npm test` before submitting changes.

## Pull requests

- Describe the change and how you tested it.
- Include or update tests when behavior changes.
- Keep documentation in sync with changes.
- Call out any known limitations or security implications.

## Security note

VaultDB is an educational demo, not an audited password manager. Do not use it to store real credentials. Please do not publish exploit details or sensitive data in public issues; contact the repository owner privately instead.
